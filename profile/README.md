## Hue2Lox

**Your Philips Hue lights and scenes in Loxone.**

Hue2Lox connects Philips Hue to Loxone locally. Manage lights and scenes across multiple Hue Bridges, copy ready-made HTTP commands, or export XML templates for Loxone Config. The web interface is available in English and German; normal operation needs no cloud account.

**Recommended setup:** Docker Compose in a Linux VM. See the installation guide for supported alternatives and current requirements.

## PLX

**Porsche Connect status for your dashboard and Loxone.**

PLX displays the vehicle data your Porsche Connect account provides and sends selected values to Loxone via MQTT. Choose the measurements your smart home receives, such as battery level, range or tire pressure, where supported by your vehicle and contract.

A compatible Porsche Connect cloud account is required. PLX reads status only: it does not remote-control or wake your car. Docker Compose is preferred; a LoxBerry 4 plugin is available as an alternative. The web interface supports English and German.

**Preview — not a stable release.** See the [latest release](https://github.com/square-com-de/plx/releases) for the current version, tested scenarios and remaining limits.
