## 🐙 Hue2Lox

**Hue im Griff. Mit Hue2Lox.**

Hue2Lox verbindet Philips Hue mit Loxone – lokal, übersichtlich und mit acht helfenden Armen.

- Lampen und Szenen über mehrere Hue Bridges verwalten
- Passende Befehle und XML für Loxone erzeugen
- Weboberfläche auf Deutsch und Englisch
- Installation mit Docker und interaktivem Assistenten

Die Veröffentlichung wird vorbereitet. Der eigene Hue2Lox-Code steht unter Apache 2.0; Drittanbieterbestandteile behalten ihre eigenen Lizenzbedingungen.
